# Moodle Importer

**Перенос Google Forms в готовые тесты Moodle: экспорт → XML/ZIP → импорт.**

[English](README.md) · [Подробная настройка](docs/setup.md)

Проект состоит из экспортёра Google Apps Script и локального плагина Moodle.
Плагин создаёт самостоятельные скрытые тесты с вопросами, баллами и изображениями:
собирать каждый тест вручную из банка вопросов не нужно.

## Возможности

- Экспорт отдельных форм или папки; автоматические пакеты с продолжением и отчётами.
- Один/несколько правильных ответов, короткий ответ, эссе и описания.
- Встраивание изображений и сборка XML в ZIP.
- Предварительный просмотр, выбор курса и раздела, создание скрытых тестов.
- Защита от повторного импорта той же формы в тот же курс.
- Проверка XML, изображений и путей ZIP; отдельная транзакция для каждого теста.

## Запуск

1. Установите папку `moodle/local/formsquiz` как `local/formsquiz` в Moodle 4.3.x.
2. Создайте проект Apps Script из файлов `exporter/`.
3. Настройте Google Forms API и `SOURCE_FOLDER_ID` по [инструкции](docs/setup.md).
4. Запустите `startFolderExport`, проверьте отчёты; после завершения — `buildMoodlePackages`.
5. Загрузите XML/ZIP на `/local/formsquiz/index.php`, проверьте план и создайте тесты.
6. Просмотрите вопросы и настройки, затем откройте тесты ученикам.

Ветки формы, ответы участников и настройки исходного теста не переносятся.
Проверьте пропущенные вопросы и ошибки в отчётах. Завершение очереди не означает,
что каждая форма экспортирована успешно. Повторный импорт не обновляет старые тесты.

Лимиты импорта: до 100 XML, 25 МиБ на XML и 100 МиБ суммарно; лимиты сервера могут быть ниже.
Поддержка заявлена для Moodle 4.3.x; другие версии в этой публикации не проверены.

Тесты Moodle PHPUnit находятся в `moodle/local/formsquiz/tests/` и используют вымышленный XML.

Рабочие формы, отчёты, ответы, ключи и реальные ID Google Диска в репозиторий не входят.
